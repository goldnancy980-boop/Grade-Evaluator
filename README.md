# Simple Grade Evaluator

A lightweight Python command-line utility that prompts users to input their score and instantly calculates their corresponding letter grade using a structured conditional system.

## Grading Scale
The program checks your score against the following thresholds:
*   **A+** $\rightarrow$ 95 or higher
*   **A** $\rightarrow$ 90 to 94
*   **B** $\rightarrow$ 80 to 89
*   **C** $\rightarrow$ 70 to 79
*   **D** $\rightarrow$ 60 to 69
*   **E** $\rightarrow$ 50 to 59
*   **F** $\rightarrow$ Below 50


##  Built With
*   **Python 3** - Utilizing clean `if-elif-else` conditional control flows.
*   **Visual Studio Code (VS Code)** - Source code editor environment.
